# 豆腐番

## ゲーム概要
倉庫番のゲーム性を再現することにフォーカスした、
豆腐が食材を運ぶ世界観のパズルゲームです。

プレイヤーは豆腐を操作し、食材を押して正しい位置へ運ぶことでステージをクリアします。
シンプルながらも思考力が求められる、クラシックなパズル体験を目指しました。

## 制作時に目指したこと・意識したこと

### ・倉庫番の再現性
元となる倉庫番のゲーム性を忠実に再現することを重視しました。  
操作感やパズルとしての成立性を崩さないよう、
ルール設計と挙動の正確さを意識して実装しています。

### ・押している“説得力”のあるアニメーション
単にオブジェクトが移動するのではなく、
「豆腐が食材を押している」と感じられるように、
アニメーションと移動処理の同期を重視しました。

---

## そのために行ったこと

### ① 描画とロジックの分離
描画処理とゲームロジックを分離することで、
見た目の調整と挙動の調整を独立して行える構造を意識しました。  
これにより、デザイン調整や仕様変更への対応を容易にしています。

### ② グリッドベースの設計
倉庫番の特性に合わせて、
マップおよびオブジェクトをグリッド単位で管理する設計を採用しました。  
これにより、判定処理の簡略化と安定した挙動を実現しています。

### ③ チーム開発における進行管理
タスクの整理と役割分担を明確にし、
短期間でも効率よく開発が進むように管理を行いました。
